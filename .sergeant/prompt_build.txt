Add Intent and Bullet as first-class records in the store. This is the store layer only: no UI wiring, no decomposition logic.

Read docs/prd-sergeant-v2.md section 3a for the domain model, and AGENTS.md first.

Domain model to implement:
  Project (a named set of repositories, already exists in internal/config)
    Intent  - a durable statement of desired change; may span repos; the PRIMARY object
      Bullet - exactly ONE repo, a vertical slice through that repo stack, implemented
               test-first, yielding one commit and one PR

Work to do in internal/store/store.go and internal/store/store_test.go:

1. Add an IntentRecord struct with: ID, Project, Statement (the durable text), Status
   (proposed, approved, in_progress, satisfied, abandoned), CreatedAt, UpdatedAt.
2. Add a BulletRecord struct with: ID, IntentID, Repo, Position (int, the merge order
   within the intent), Status (pending, red, green, sealed, merged, failed), Branch,
   Worktree, CommitSHA, PRURL, CreatedAt, UpdatedAt.
3. Add both tables to the schema string, and add them to migrateAddColumns style
   handling so an EXISTING database gains them. Follow the pattern already used for the
   runs.brief column: CREATE TABLE IF NOT EXISTS is a no-op on an existing table, so
   verify with PRAGMA and add what is missing.
4. Add store methods: CreateIntent, GetIntent, ListIntentsForProject, UpdateIntentStatus,
   CreateBullet, ListBulletsForIntent (ordered by Position), UpdateBulletStatus.
5. Guard JSON-ish text the same way existing code does, and use time.Now().UTC() for
   timestamps to match CreateRun.

Tests required in internal/store/store_test.go:
- Create an intent with two bullets in different repos and assert ListBulletsForIntent
  returns them ordered by Position.
- Assert a bullet is scoped to exactly one repo (the Repo field is a single string, and
  a test documents that cross-repo work is a second bullet).
- Assert the migration works: open a store, close it, reopen it, and confirm the intents
  and bullets tables exist and are usable. This is the case that broke before.
- Assert UpdateIntentStatus and UpdateBulletStatus move status and bump UpdatedAt.

Constraints: do not shell out to any bin/sgt-* script. Do not use tmux. Do not modify
the UI. Run go build ./... and go test ./internal/... -count=1 before finishing.
